# Antigravity (agy) Delegation Skill

Этот скилл позволяет OpenAI Codex взаимодействовать с агентом **Google Antigravity CLI** (`agy`) и передавать ему задачи на анализ, рецензирование, архитектурное проектирование или автономное выполнение в рабочей директории.

---

## 1. Когда делегировать в Antigravity (agy)

### Делегируй в agy, когда:
- **Анализ большого контекста или кодовой базы**: Gemini обладает огромным контекстным окном, отлично подходящим для сквозного аудита репозиториев, поиска зависимостей и понимания крупных архитектур.
- **Второе экспертное мнение (Second Opinion)**: Сверка сложных архитектурных решений, проверка граничных случаев, валидация паттернов проектирования.
- **Генерация масштабных шаблонов и бойлерплейта**: Написание рутинных тестов, моков, миграций, DTO и спецификаций API.
- **Параллельное проектирование**: Составление планов миграции или плана реализации через `plan`-режим Antigravity.
- **Прямой запрос пользователя**: Пользователь явно просит "спроси у agy", "делегируй в Gemini/Antigravity", "узнай мнение Antigravity".

### Решай самостоятельно в Codex (НЕ делегируй):
- Локальные точечные правки, синтаксический фикс одной строки.
- Задачи, требующие глубоких математических доказательств или узких низкоуровневых оптимизаций, в которых специализируется текущая модель Codex.

## 2. Режимы делегирования и инструменты

Для делегирования используется готовый скрипт:
`~/.codex/skills/agy-delegation/scripts/delegate_agy.py`

### Режим A: Консультация / Анализ (По умолчанию, Рекомендуется)
Antigravity запускается в режиме планирования/чтения (`--mode plan`) и не вносит изменений в файлы проекта на диске. Codex получает чистый ответ, анализирует его и решает, как применить рекомендации.

```bash
python3 ~/.codex/skills/agy-delegation/scripts/delegate_agy.py \
  --mode consult \
  -p "Проанализируй архитектуру кэширования и предложи стратегию инвалидации для multi-tenant приложения"
```

С передачей файлов контекста:
```bash
python3 ~/.codex/skills/agy-delegation/scripts/delegate_agy.py \
  --mode consult \
  -p "Проверь код на утечки ресурсов и соответствие best practices" \
  --context-files src/server.ts src/cache.ts \
  --json
```

### Режим B: Прямое выполнение в воркспейсе (Workspace Execution)
Antigravity запускается в режиме применения правок (`--mode accept-edits --dangerously-skip-permissions`) в целевом репозитории и автономно редактирует файлы:

```bash
python3 ~/.codex/skills/agy-delegation/scripts/delegate_agy.py \
  --mode exec \
  -C /path/to/project \
  -p "Напиши интеграционные тесты для API авторизации в src/tests/auth.test.ts"
```

> [!IMPORTANT]
> При использовании режима `exec` обязательно проверяй результат через `git status` и `git diff` до и после выполнения!

## 3. Пошаговый алгоритм действий для Codex

1. **Сформулируй задачу и подготовь контекст**:
   - Четко определи цель и ограничения.
   - Собери пути к нужным файлам для аргумента `--context-files`.

2. **Запусти скрипт делегации**:
   - Выполни вызов `delegate_agy.py` через системную команду.
   - По умолчанию используй `--mode consult`.
   - Если требуется программный разбор ответа, добавь флаг `--json`.

3. **Обработай ответ**:
   - Изучи рекомендации Antigravity.
   - Проверь корректность предложенного кода или решения.
   - Синтезируй финальный ответ пользователю либо внеси нужные изменения в код проекта.

4. **Продолжение диалога (сессии)**:
   - Если нужно уточнить или продолжить предыдущую сессию, можно использовать флаг `--continue`:
   ```bash
   agy -p "Уточни пункт 2 и покажи реализацию на TypeScript" --continue
   ```
