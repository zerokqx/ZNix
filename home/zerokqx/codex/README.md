# Настройки Codex

Модуль Home Manager восстанавливает недостающие файлы в `~/.codex` и `~/.agents/skills`. Существующие файлы сохраняются. `config.toml` остаётся доступен для редактирования из Codex. Чтобы обновить настройки для следующей установки, перенесите нужные изменения из локального файла в этот каталог.

Здесь хранятся предпочтения CLI и Desktop, настройки MCP и плагинов, глобальные инструкции, роли, правила React и собственные навыки. Два локальных MCP-сервера (`libreoffice-writer` и `project-mcp`) требуют установки соответствующих проектов. Встроенные плагины и навыки загружает сам Codex.

На новой машине заново войдите в аккаунт, подключите нужные сервисы и подтвердите доверие к проектам, хукам и командам. Токены, история чатов, память и кэши в этот каталог не входят.
