# Oko report

Формируй краткий отчёт «Выполнено» за прошлый календарный день для Project Manager.

## Шаги

1. Возьми вчерашние коммиты со всех веток: `git log --all --since="yesterday 00:00" --until="today 00:00" --no-merges --format="%s"`. Если пользователь назвал другую дату, используй её.
2. При необходимости посмотри `git diff --stat` за этот период, чтобы понять суть неочевидных коммитов.
3. Сгруппируй коммиты по смыслу и опиши результат для пользователя продукта.

## Формат ответа

Одна строка: изменения через запятую, без нумерации и списков. Начни с «Выполнено:». Пример: `Выполнено: добавили страницу уведомлений, исправили смену почты, показали билет после активации промокода.`

## Правила

- Пиши на русском, от лица команды («добавили», «исправили», «подключили»), коротко.
- Описывай, что получил пользователь или продукт, а не как это сделано.
- Не упоминай рефакторинг, DX, тесты, CI, линтеры, документацию, переименования, названия файлов, хуков, компонентов и библиотек.
- Объединяй однотипные коммиты в один пункт.
- Если после фильтрации ничего не осталось, так и скажи.
- Не добавляй шутки и вступления: только итоговую строку.
