================================================================================
                       ⚡ ZNIX NEOVIM CHEATSHEET & GUIDE ⚡
================================================================================

[ Навигация по окну справки:  j/k - вниз/вверх  |  q / Esc - закрыть окно ]

--------------------------------------------------------------------------------
1. 📂 НАВИГАЦИЯ И ПОИСК (Snacks.picker)
--------------------------------------------------------------------------------
  <leader><Space>    - Поиск файлов в текущем проекте (Snacks.picker.files)
  <leader>e          - Открыть / закрыть файловый проводник (Snacks.explorer)
  <leader>/          - Глобальный поиск текста по проекту (Live Grep)
  <leader>sw         - Поиск слова под курсором в проекте
  <leader>,          - Переключение между открытыми буферами
  <leader>fr         - Недавние открытые файлы (Recent Files)
  <leader>sp         - Быстрое переключение проектов
  <leader>su         - История отмен (Undo Tree picker)
  <leader>sk         - Поиск по всем доступным хоткеям (Keymaps picker)
  <leader>s"         - Просмотр и вставка регистров (Registers)

--------------------------------------------------------------------------------
2. 🧠 LSP И ИНТЕЛЛЕКТУАЛЬНЫЙ КОДИНГ (Language Server Protocol)
--------------------------------------------------------------------------------
  gd                 - Перейти к определению (Go to Definition)
  gr                 - Показать все использования / ссылки (References)
  gI                 - Перейти к реализации интерфейса/типа (Implementations)
  gy                 - Перейти к типу определения (Type Definition)
  K                  - Документация / Hover подсказка
  <leader>ca         - Code Action (Авто-фиксы, импорты, рефакторинг)
  <leader>cr / rn    - Rename (Переименовать переменную/функцию везде)
  <leader>cR         - Rename File (Переименовать текущий файл с авто-обновлением)
  <leader>cf         - Format (Форматирование через Conform + Prettier/Nixfmt)
  <leader>cd         - Показать диагностику / ошибку в текущей строке
  <leader>cD         - Список всех ошибок в текущем файле
  <leader>sd         - Список всех ошибок во всем проекте

--------------------------------------------------------------------------------
3. 🐙 РАБОТА С GIT (Snacks & Gitsigns)
--------------------------------------------------------------------------------
  <leader>gg         - Открыть терминальный Lazygit во всплывающем окне
  <leader>gh / hp    - Превью изменений в текущем блоке (Git Hunk preview)
  <leader>hs         - Застейджить текущий блок (Stage hunk)
  <leader>hr         - Сбросить изменения в блоке (Reset hunk)
  <leader>gb         - Включить / выключить Git Blame текущей строки
  <leader>gl         - История коммитов (Git Log)
  <leader>gd         - Просмотр Git Diff изменений
  <leader>gB         - Открыть текущий файл в GitHub / GitLab (Git Browse)
  ]h / [h            - Переход к следующему / предыдущему блоку изменений

--------------------------------------------------------------------------------
4. 📑 БУФЕРЫ, ОКНА И ТАБЫ
--------------------------------------------------------------------------------
  <S-h> / <S-l>      - Переключение между вкладками буферов (влево / вправо)
  <leader>bd         - Закрыть текущий буфер (без закрытия сплита)
  <leader>bo         - Закрыть все остальные буферы кроме активного
  <leader>bO         - Закрыть вообще все буферы
  <leader>wa         - Принудительно сохранить все файлы (:wa!)
  <leader>qq         - Выйти из Neovim (:qa!)

  <leader>wv         - Вертикальный сплит окна
  <leader>ws         - Горизонтальный сплит окна
  <leader>wd         - Закрыть текущее окно (:close)
  <leader>wo         - Оставить только текущее окно (:only)
  <leader>wr         - Поменять окна местами
  <leader>w=         - Выровнять размеры всех окон
  <A-h/j/k/l>        - Изменение размера текущего окна (влево/вниз/вверх/вправо)

--------------------------------------------------------------------------------
5. ⚡ ИНСТРУМЕНТЫ (Snacks & Mini)
--------------------------------------------------------------------------------
  <C-/> / <leader>tt - Вызвать плавающий терминал (Toggle floating terminal)
  <leader>z          - Zen Mode (Фокусировка на тексте без отвлечений)
  <leader>Z          - Zoom (Развернуть окно на весь экран)
  <leader>.          - Scratch Buffer (Быстрый черновик / заметка)
  <leader>S          - Выбрать сохраненный Scratch-буфер
  <leader>n          - История всплывающих уведомлений (Notifier history)
  <leader>un         - Очистить / скрыть все уведомления
  ]] / [[            - Прыжок к следующему / предыдущему повторению слова

--------------------------------------------------------------------------------
6. 🎯 БЫСТРОЕ РЕДАКТИРОВАНИЕ (Flash & Mini.nvim)
--------------------------------------------------------------------------------
  s                  - Flash Jump (Мгновенный прыжок в любую точку экрана по 2 буквам)
  S                  - Flash Treesitter (Выделение синтаксических блоков)
  gcc                - Закомментировать / раскомментировать строку
  gc (visual)        - Закомментировать выделенный блок
  sa + символ        - Обернуть в скобки/кавычки (Mini.surround add)
  sd + символ        - Удалить обрамляющие скобки/кавычки (Mini.surround delete)
  sr + стар + нов    - Заменить обрамление (Mini.surround replace)
  <A-j> / <A-k> (vis)- Перемещение выделенных строк вверх / вниз (Mini.move)

--------------------------------------------------------------------------------
7. 🗂️ СВОРАЧИВАНИЕ КОДА (Treesitter Folds)
--------------------------------------------------------------------------------
  za                 - Свернуть / развернуть блок под курсором (или клик по )
  zc / zo            - Принудительно свернуть (Close) / развернуть (Open) блок
  zR / zM            - Развернуть ВСЁ в файле (Open all) / свернуть ВСЁ (Close all)
  <leader>ct         - Rust: Свернуть / развернуть все тесты (#[test], mod tests)
