# material-you-icons

Пакет строит тему иконок приложений Material You для ZNix. Он читает `Icon=` из установленных ярлыков, ищет оригиналы в XDG, профилях NixOS и Flatpak, отдавая предпочтение `hicolor`. Тема наследует настроенный в ZNix вариант Papirus. Для иконок, которых нет в генерации, приложения используют наследование темы. Ярлыки с абсолютным путём в `Icon=` продолжают использовать этот файл.

Для однотонных плашек знак выделяет цветовой алгоритм. Для более сложных значков MobileSAM выбирает маску, а рендерер сохраняет внутренние детали несколькими тонами. Смена палитры Stylix использует сохранённые маски из `$XDG_CACHE_HOME/material-you-icons/masks`.

Команда `render-icon` доступна в пользовательском профиле. Для разового прогона можно указать отдельную папку.

```sh
render-icon install --theme-dir /tmp/MaterialYou --inherits Papirus-Dark
render-icon render /path/to/input.png /tmp/output.png
```

На рабочем столе тема хранится в `$XDG_DATA_HOME/icons/MaterialYou`. Для явного обновления после установки приложений можно запустить `systemctl --user restart material-you-icons.service`. Приложения, которые кэшируют иконки, увидят их после перезапуска приложения или следующего входа в сессию.

На хосте `desktop` Home Manager запускает MobileSAM на Radeon через ROCm. Пакет использует закреплённое окружение из `rocm/uv.lock` и хранит его в `$XDG_CACHE_HOME/material-you-icons/rocm-7.2-py313`. На новой машине подготовка окружения может скачать несколько гигабайт. Она выполняется в пользовательской службе в фоне после запуска активации. Для других хостов сохраняется пакет с CPU-версией PyTorch.
